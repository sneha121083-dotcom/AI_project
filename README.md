# Titanic Survival Prediction

## About the Project
This project uses the Titanic passenger dataset to predict whether a passenger survived the Titanic disaster using machine learning classification algorithms.

## Dataset
The dataset contains passenger information such as age, sex, passenger class, fare, and survival status.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Workflow
1. Loaded and explored the Titanic dataset.
2. Performed exploratory data analysis (EDA) using histograms, bar charts, and heatmaps.
3. Handled categorical features through encoding.
4. Applied feature scaling and data preprocessing.
5. Trained and evaluated multiple machine learning models.
6. Compared model performance using accuracy, F1-score, and classification metrics.

## Machine Learning Models
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

## Results

| Model | Accuracy | F1-score |
|---|---:|---:|
| Logistic Regression | 80.45% | 72.44% |
| Decision Tree | 82.12% | 76.12% |
| Random Forest | 80.45% | 72.87% |

Based on these results, the Decision Tree Classifier achieved the highest accuracy and F1-score among the three models tested.

## How to Run
1. Clone or download this repository.
2. Open the notebook in Google Colab or Jupyter Notebook.
3. Upload the Titanic dataset if it is not already included.
4. Run the notebook cells in sequence.
